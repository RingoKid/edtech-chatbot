# Georgia Standards for Handwriting & Spelling Lessons

Curated reference of state standards for letter-level handwriting and spelling instruction only.
Includes only standards relevant to single-letter/sound lessons for PreK, Kindergarten, and 1st Grade.
Standards for rhyme, compound words, syllables, decoding, and motor skills are intentionally excluded.

> **Source documents:**
> - PreK: `48-60_Indicators.pdf` (GELDS — Georgia Early Learning and Development Standards)
> - Kindergarten: `Georgia's K-12 English Language Arts Standards (SY2025-2026).pdf`
> - 1st Grade: `Standards Language Arts_Grade 1.pdf`

---

## PreK — GELDS (48-60 Months)

PreK uses a different standards system from K-12. Published by Georgia's Department of Early Care and Learning (Bright from the Start). Codes use the format `CLL6.4a` (Domain + Standard + Age Band + Indicator).

### Communication, Language, and Literacy (CLL)

**Standard CLL6: The child will develop early phonological awareness (awareness of units of sound).**

| Code | Description |
|------|-------------|
| CLL6.4c | Isolates the initial (beginning) sounds in words with adult guidance |
| CLL6.4e | Segments words into syllables |
| CLL6.4f | Manipulates and blends sounds (phonemes) with adult guidance |

**Standard CLL7: The child will demonstrate increasing knowledge of the alphabet.**

| Code | Description |
|------|-------------|
| CLL7.4a | With prompting and support, recognizes and names some upper and lower case letters of the alphabet |

**Standard CLL8: The child will demonstrate awareness of print concepts.**

| Code | Description |
|------|-------------|
| CLL8.4b | Understands that letters form words. Understands that words are separated by spaces in print |

**Standard CLL9: The child will use writing for a variety of purposes.**

| Code | Description |
|------|-------------|
| CLL9.4d | Writes some letters of the alphabet |

## Kindergarten — Georgia K-12 ELA Standards (SY2025-2026)

Codes use the format `K.F.PA.6.a` (Grade.Domain.BigIdea.Standard.Sub-standard).

### K.F.PA — Phonemic Awareness

**K.F.PA.6 Phonemic Awareness** — Identify and manipulate the individual sounds in spoken words.

| Code | Description |
|------|-------------|
| K.F.PA.6.a | Isolate and pronounce initial, final, and then medial sounds in spoken words with three phonemes |
| K.F.PA.6.b | Identify short and long vowel sounds in spoken one-syllable words |
| K.F.PA.6.c | Blend, count, and segment up to three phonemes in spoken one-syllable words |
| K.F.PA.6.d | Add, delete, and substitute phonemes in spoken one-syllable words with up to three phonemes |

### K.F.P — Phonics

**K.F.P.1 Phoneme-Grapheme Correspondences** — Identify and produce phoneme-grapheme correspondences.

| Code | Description |
|------|-------------|
| K.F.P.1.a | Identify and produce basic one-to-one phoneme-grapheme correspondences for the most frequently used sound for each consonant |
| K.F.P.1.b | Identify and produce both long and short vowel sounds for A, E, I, O, U |

**K.F.P.3 Encoding with Phonics** — Use grade-level phonics skills to encode words in context and in isolation.

| Code | Description |
|------|-------------|
| K.F.P.3.a | Use knowledge of letter/sound correspondences to connect letters (graphemes) to sounds (phonemes) to encode simple one-syllable words, including high-frequency words (VC, CV, CVC) |
| K.F.P.3.b | Identify and encode irregularly spelled high-frequency words |

### K.F.H — Handwriting

**K.F.H.1 Motor Skills & Letter/Word Formation** — Use fine motor skills to form legible letters and words in print.

| Code | Description |
|------|-------------|
| K.F.H.1.a | Form all uppercase and lowercase letters |
| K.F.H.1.b | Form words, including first and last names |
| K.F.H.1.c | Use appropriate spacing between letters, words, and sentences |

**K.F.H.2 Transcription & Handwriting Fluency** — Use working memory skills to transcribe oral language to written text and maintain meaning while writing letters, words, and sentences quickly and accurately.

| Code | Description |
|------|-------------|
| K.F.H.2.a | Practice basic transcription skills |
| K.F.H.2.b | Begin building handwriting fluency by forming accurate letters, including those in first and last names |

## 1st Grade — Georgia K-12 ELA Standards (SY2025-2026)

Same coding system as Kindergarten, with `1.` prefix. Note: K.F.PA.1 (Rhyme), K.F.PA.2 (Words & Sentences), and K.F.PA.3 (Compound Words) are Kindergarten-only and do not apply to 1st grade.

### 1.F.PA — Phonological Awareness

**1.F.PA.4 Syllables** — Identify and manipulate syllables in spoken words.

| Code | Description |
|------|-------------|
| 1.F.PA.4.d | Add, delete, and substitute syllables in spoken words |

**1.F.PA.5 Onsets & Rimes** — Blend and segment onsets and rimes in spoken words.

| Code | Description |
|------|-------------|
| 1.F.PA.5.a | Blend onsets and rimes of spoken one-syllable words with blends, digraphs, and trigraphs in the initial and final positions |
| 1.F.PA.5.b | Segment onsets and rimes of spoken one-syllable words with blends, digraphs, and trigraphs in the initial and final positions |

**1.F.PA.6 Phonemic Awareness** — Identify and manipulate the individual sounds in spoken words.

| Code | Description |
|------|-------------|
| 1.F.PA.6.a | Isolate and pronounce initial, medial, and final sounds in spoken one-syllable words, including words with digraphs and blends |
| 1.F.PA.6.b | Distinguish between short and long vowel sounds in spoken one-syllable words |
| 1.F.PA.6.c | Blend and segment up to five phonemes, including consonant blends and digraphs, in spoken one-syllable words |
| 1.F.PA.6.d | Add, delete, and substitute phonemes in spoken one-syllable words with three or more phonemes |

### 1.F.P — Phonics

**1.F.P.1 Phoneme-Grapheme Correspondences** — Identify and produce phoneme-grapheme correspondences.

| Code | Description |
|------|-------------|
| 1.F.P.1.a | Identify and produce phoneme-grapheme correspondences for frequently used consonant blends and digraphs |
| 1.F.P.1.b | Identify and produce both long and short vowel sounds for A, E, I, O, U, including final -e and vowel digraphs |

**1.F.P.3 Encoding with Phonics** — Use grade-level phonics skills to encode words in context and in isolation.

| Code | Description |
|------|-------------|
| 1.F.P.3.a | Encode regularly spelled one-syllable words with a variety of spelling patterns (VC, CVC, CVCe, VCC, CCVC, CVCC, CCVCC), including high-frequency words |
| 1.F.P.3.b | Identify and encode irregularly spelled words, including high-frequency words |
| 1.F.P.3.c | Encode one-syllable nonsense words with a variety of spelling patterns (VC, CVC, CVCe, VCC, CCVC, CVCC, CCVCC) |
| 1.F.P.3.d | Encode two-syllable words with basic patterns by applying knowledge of basic syllable types |

### 1.F.H — Handwriting

**1.F.H.1 Motor Skills & Letter/Word Formation** — Use fine motor skills to form legible letters and words in print.

| Code | Description |
|------|-------------|
| 1.F.H.1.a | Form all uppercase and lowercase letters and words with accuracy and consistency |
| 1.F.H.1.b | Form words with accuracy and consistency |
| 1.F.H.1.c | Use appropriate spacing between letters, words, and sentences across lines on a page |

**1.F.H.2 Transcription & Handwriting Fluency** — Use working memory to transcribe oral language to written text and maintain meaning while writing letters, words, and sentences quickly and accurately.

| Code | Description |
|------|-------------|
| 1.F.H.2.a | Perform basic transcription skills |
| 1.F.H.2.b | Build handwriting fluency by accurately and quickly forming all uppercase and lowercase letters |
